# واجب فلاتر (WeekHomeWork)

نموذج تسجيل شامل مبني بإطار عمل فلاتر (Flutter) يطبّق جميع أدوات الإدخال والتفاعل مع التحقق (Validation) في شاشة واحدة.

## الأدوات المضمّنة

| الأداة | التحقق |
| ------ | ------ |
| TextField (الاسم) | بدون تحقق (إدخال عادي) |
| TextFormField (البريد) | يجب أن يحتوي على @ |
| TextFormField (الهاتف) | يجب أن يكون 10 أرقام |
| TextFormField (حقل مطلوب) | لا يسمح بالقيم الفارغة |
| Checkbox (الموافقة) | يجب أن يكون محدّداً (True) |
| Radio (الجنس) | يجب اختيار خيار واحد |
| Switch (الإشعارات) | ليس له تحقق |
| Slider (الخبرة) | القيمة بين 0 و 10 |
| RangeSlider (العمر) | البداية أصغر من النهاية |
| DropdownButton (المدينة) | يجب اختيار مدينة |
| PopupMenuButton (اللغة) | يجب اختيار لغة |

## آلية العمل

- تُستخدم `Form` مع `GlobalKey<FormState>` للتحقق من جميع الحقول مرة واحدة.
- زر «إرسال» (`ElevatedButton`):
  - إذا كانت جميع البيانات صحيحة تظهر نافذة `AlertDialog` تعرض ملخص كل القيم المدخلة.
  - إذا كان هناك خطأ تظهر رسالة الخطأ تحت الحقل المطلوب.
- زر «إعادة تعيين» (`TextButton`) لمسح جميع الحقول وإعادة القيم الافتراضية.

## التشغيل

```bash
flutter pub get
flutter run
```
